# Vivek Portfolio

A responsive, single-page portfolio inspired by the supplied reference video: black editorial layout, oversized red outline title, red nameplate, project archive, skills matrix and contact section.

## Run locally.

Open `index.html` in a browser. No build step is required .

## Deploy.

Import this folder/repository into Vercel as a static site, or drag the folder into a static hosting provider.

## Before publishing

- Confirm the Dual LLM project description and add its direct repository/demo URL.
- Add your preferred public contact email if you want an email link; the current contact action points to LinkedIn.
- Add a real portrait by replacing the stylized initial in `.portrait` with an image if desired.
- Verify each project description and link reflects the latest deployed version.
